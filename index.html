Pelajari tentang Pos-El ID
Pos-El adalah pesan jadul ala BBM: daftar hanya pakai username, nama, dan password — tanpa email, tanpa nomor HP. Setiap akun dapat PIN 8 karakter, tambah teman pakai PIN, lalu chat, PING!, buat grup, dan kirim broadcast. Akun tersimpan di Supabase dan sinkron antar HP.

⚙️ Pengaturan Supabase (untuk sinkron antar HP)

Supabase URL sudah diisi dan kunci anon sudah ditanam di aplikasi, jadi kamu tidak perlu mengisi apa-apa. Kalau mau mengganti kunci, tempel anon public key dari dashboard Supabase kamu (Settings → API) di bawah ini. Kunci yang ditempel tersimpan hanya di HP ini dan menggantikan kunci bawaan.

Belum ada tabel di Supabase? Jalankan file supabase/schema.sql dari repo ini di SQL Editor, dan matikan Confirm email di Authentication → Settings. Kalau tidak diisi, aplikasi jalan dalam Mode Lokal (demo, hanya di HP ini).
